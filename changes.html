2026年10月19日 / サービスと料金

リール編集と多言語対応、SNS運用プランを始めました

リールの編集
お店で撮った動画を、字幕つき・15〜30秒の縦長のリールに編集します。1本5,500円（税込）です。
多言語メニュー
日本語・英語・中国語・韓国語を切り替えられるメニューのページと、テーブル用のQRカードを、20品まで19,800円（税込）でお作りします。
サイト全体の多言語化
店舗紹介サイトを作るときに、サイトの全部を英語・中国語・韓国語に切り替えられるようにするオプションを、19,800円（税込）で加えました。メニューだけか、サイト全体かを選べます。
SNS運用プラン
毎月の営業カレンダー画像と、リールの編集を月4本まで、月19,800円（税込）でお受けします。最低利用期間などの条件は月額サポートと同じです。

2026年10月11日 / 料金と支払い

先着5件の価格の呼び方と、お支払いのしかたを変えました

呼び方
「モニター価格」という呼び方をやめ、「先着5件の価格」に統一しました。29,800円であること、6件目からは49,800円になること、制作例としての紹介と公開後のご感想が条件であることは変わりません。
お支払い
先着5件の価格でお申し込みの場合は、着手金をいただかないことにしました。サイトの公開後に請求書をお送りし、公開日から7日以内に全額をお支払いいただきます。通常価格の着手前50％・公開前50％は変わりません。
お支払いが確認できないとき
期限を過ぎても入金が確認できない場合は、あらかじめご連絡のうえ、お支払いが確認できるまでサイトを一時的に非公開にすることがあります。契約書にも同じ内容を記載しています。

2026年10月1日 / 規約の改定

個人としてご契約の場合の条件を分け、損害賠償の上限を直しました

対象
事業のためではなく、個人としてご契約いただく場合です。お店や会社、個人事業としてのご依頼はこれまでどおりです。
制作の確認期間
最終版をお渡ししてから確認完了とみなすまでの期間を、7日から14日にしました。
月額サポート
最初の契約期間を3か月から1か月にしました。この1か月が最低利用期間で、そのあとは1か月ごとの自動更新です。
損害賠償の上限（月額サポート）
「損害の原因が生じた月の前月までの3か月分」から「その月を含む直近3か月分（契約期間が3か月に満たない場合はその期間分）」に改めました。これまでの書き方では、契約した最初の月の上限が0円になっていたためです。すべてのお客さまが対象です。

2026年9月18日 / メニュー

上のメニューを、いつでも見えるようにしました

これまで
画面の幅が狭いと、メニューの項目が隠れ、右上のボタンを押さないとページを移動できませんでした。
これから
サービス・制作例・料金・準備ガイド・TANOMATOについての5つと「無料相談」は、スマホでも上に並んだままになります。幅が足りないときは横に滑らせて見られます。
メニューボタン
右上のボタンは残し、押すとサイト内のすべてのページ（制作の流れ、業種別の案内、変更履歴、規約、特定商取引法に基づく表記など）を一覧で開けるようにしました。

2026年9月18日 / 操作のしやすさ

マウスの矢印を、隠さないようにしました

これまで
パソコンで見たとき、端末のマウス矢印を隠して、ページ側で丸い印を描いていました。ページの処理が混み合うと印の動きだけが遅れ、矢印が止まったように見えることがありました。
これから
端末のマウス矢印をそのまま表示します。ページ側の印は、リンクやボタンなど押せる場所に重なったときだけ出ます。
制作例
3つの制作例も同じ動きにそろえ、押せない場所でも印が出たままになる不具合を直しました。

2026年9月18日 / 制作例

3つの制作例を、作り直しました

カフェの店舗案内
縦書きの見出し、いま営業中かの表示、種類ごとに切り替わるメニュー、スクロールで朝から夕方へ色が移る過ごし方の紹介を加えました。
会社の案内（土木工事会社）
何の会社かが最初の一行で分かるように、題材を札幌の土木工事会社にしました。動く等高線の背景、よくあるご相談、工事の内容、ご連絡から着工までの流れ、会社概要の3ページです。
相談会の案内（リフォーム会社）
題材を、リフォーム会社がひらく無料相談会にしました。次回の開催日を自動で計算するカウントダウン、三つ選ぶだけで当日の相談メモができるコーナー、スクロールで進む60分の時計を入れています。
共通
書体は使う文字だけに絞ってサイト内に置き、外部へ閲覧情報を送らない形にしました。スマホ表示と、端末で「動きを減らす」設定をしている場合の表示も確認しています。制作例一覧などの画像も新しい画面に差し替えました。

2026年9月17日 / 料金と対応範囲

料金の目安を、先に分かるように

モニター価格
1ページ29,800円を、制作実績としての紹介とご感想へのご協力を条件とするモニター価格（先着5件）にしました。
LP・企業サイト
個別見積もりだった料金に目安を付けました。LPは59,800円〜、企業サイトは5ページ109,800円〜、ページの追加は16,500円〜です。
作業ごとの料金表
公開後の修正、公開や検索の設定、SNS投稿用の画像、名刺の料金を、月額契約の有無で並べて示しました。
対応範囲
文章の新規作成や取材、チラシ・バナー・ロゴのデザイン、写真撮影、広告やアクセス解析の設定は受け付けないことにしました。
修正回数
1ページ制作の修正を、初稿後に1回と最終確認で1回の計2回にしました。
月額サポートの特典
料金表の近くに、月額サポートで受けられる内容をまとめました。管理プランに、ドメインと証明書の期限のお知らせを加えました。
受付と納期
同時にお受けする制作を3件までとし、お急ぎの場合の特急対応を設けました。ほかのお客さまとの納期は変えません。

2026年9月17日 / 動きの追加

見ていて楽しい、動きのあるサイトに

オープニングとページ移動
最初の表示で、ばらばらの文字が「TANOMATO.」にまとまる演出を追加しました。ページを移るときは色の幕が切り替わります。
スクロールの動き
見出しや制作例が順番に現れ、数字がカウントアップし、見出しにマーカーが引かれます。読み進めた位置を上部のバーで示します。
触れる楽しさ
マウス操作では、カーソルが案内の形に変わり、カードやボタンがわずかに反応します。トップの空いた場所をクリックすると紙吹雪が出ます。
配慮
端末で動きを減らす設定（iPhoneの「視差効果を減らす」など）をしている場合は、動きをすべて止めて表示します。スマホではカーソルの演出を使いません。

利用規約と個人情報の取り扱いを改定しました

事業者情報

著作権が移る時期、確認完了の扱い（原則7日）、無償修正の期間（原則30日）、損害賠償の上限、支払期限と振込手数料、再委託の扱いを明記しました。
月額サポート
支払期限と、初回3か月間の解約日の扱いを明記しました。
共通
秘密の保持、反社会的勢力の排除、準拠法と管轄を追加しました。

2026年9月15日 / 第1弾・第2弾

トップページ

相談内容の引き継ぎ
制作例に加え、選んだサービス・プラン・業種を問い合わせへ引き継ぐようにしました。
問い合わせ画面
記入例と相談後の流れを追加。Googleフォームを接続できる構成と、メールの代替手段を用意しました。
業種別の案内

制作例の解説
4つの自主制作例に、想定する課題・設計の工夫・費用条件・関連例へのリンクを追加しました。
